Abstract

This project addresses the development of a real-time pedagogical Digital Twin for nonlinear structural mechanics, combining Isogeometric Analysis (IGA) with projection-based Reduced Order Modelling (ROM) techniques.

The methodology relies on Non-Uniform Rational B-Splines (NURBS) basis functions for exact geometric representation and employs Proper Orthogonal Decomposition (POD) via Singular Value Decomposition (SVD) to extract dominant deformation modes from parametric snapshot databases. A Galerkin projection framework reduces the dimensionality of the governing equations, while hyper-reduction strategies (DEIM, ECSW) accelerate the evaluation of nonlinear internal force terms.

The resulting web-based application enables real-time simulation of geometrically nonlinear 2D structures with parametric control, achieving solve times under 10 ms compared to several seconds for the full-order model. The platform serves as both a research validation tool and an interactive pedagogical environment for teaching advanced computational mechanics.

Research Objectives & Problematic

  • Nonlinear Operator Dependence: Resolving the computational bottleneck where the tangent stiffness matrix $\mathbf{K}_T(\mathbf{u})$ changes at every Newton–Raphson iteration.
  • Geometric Parameterization: Leveraging parameter-dependent NURBS control points $\mathbf{P}_i(\mu)$ so the physical domain changes without invalidating reference coordinates.
  • Real-Time Client-Side Execution: Deploying a complete IGA and ROM solver directly in the browser via JavaScript and WebGL (Three.js) without any server-side dependencies.
  • Pedagogical Accessibility: Democratizing computational mechanics through interactive visual sandboxes that allow students to explore $h$-, $p$-, and $k$-refinements in real time.
