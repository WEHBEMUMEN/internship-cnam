% ==============================================================================
\chapter{Simulation: Full Order Model (FOM)}
\label{ch:fom}
% ==============================================================================



Equipped with the reference pullback transformation derived in Chapter \ref{ch:pullback}, high-fidelity Full Order Model (FOM) simulations can now be evaluated consistently on $\hat{\Omega}$ to collect transient snapshot datasets and benchmark reduced order approximations. This chapter formulates the implicit dynamic time integration scheme, presents baseline stress and displacement field solutions, and demonstrates the severe computational bottleneck ($\approx 450\,\text{ms}$ per time step) that prevents real-time execution without model reduction.

% ------------------------------------------------------------------------------
\section{Governing Dynamic Equations \& Flowchart}
% ------------------------------------------------------------------------------

Here, we formulate the semi-discrete dynamic equilibrium equations and compare physical-domain remeshing against reference-mapped integration.

The high-fidelity transient response of the structural continuum is governed by the semi-discrete second-order system, where we solve for the control point structural displacement vector $\vect{U}(t) \in \mathbb{R}^{N_{\text{dof}}}$ (representing the discrete physical displacements defined over the invariant reference domain):

\begin{equation}
    \mat{M}(\boldsymbol{\mu}) \ddot{\vect{U}}(t) + \mat{C}(\boldsymbol{\mu}) \dot{\vect{U}}(t) + \mat{K}(\boldsymbol{\mu}) \vect{U}(t) = \lambda(t) \mathbf{F}_{\text{ext}}, \quad \text{with } \vect{U}(0) = \mathbf{0}, \, \dot{\vect{U}}(0) = \mathbf{0}
\end{equation}

where $\mat{M}$ is the consistent mass matrix, $\mat{C} = \alpha_M \mat{M} + \beta_K \mat{K}$ is the Rayleigh damping matrix, and $\mat{K}$ is the stiffness matrix. Figure \ref{fig:remesh_vs_pullback} illustrates the computational flowchart comparing classical physical remeshing with reference domain assembly.

Comparing the two assembly paths (Figure \ref{fig:remesh_vs_pullback}) highlights how reference pullback mapping replaces full physical remeshing with invariant evaluation. In the classical path, varying the shape parameters $\boldsymbol{\mu}$ forces a complete regeneration of the physical mesh and re-evaluation of the NURBS basis functions $R_i(\boldsymbol{\mu})$ on the deformed domain. The reference mapping path bypasses this remeshing step by utilizing parameter-independent reference basis functions $\hat{R}_i$, shifting the parameter dependency entirely into the integration Jacobians. However, assembling the pulled-back stiffness $\hat{\mat{K}}(\boldsymbol{\mu})$ and mass $\hat{\mat{M}}(\boldsymbol{\mu})$ matrices at each time step remains the primary computational bottleneck of the Full Order Model (requiring an assembly time of $\approx 142.1\,\text{ms}$ as detailed in Table \ref{tab:hyper_reduction_metrics}, and up to a total of $\approx 450\,\text{ms}$ per step when recovering stress fields as shown in Table \ref{tab:fom_parameters}). This bottleneck prohibits real-time dynamic simulation and directly motivates the need for Galerkin dimensionality reduction and hyper-reduction, as shown on the right of the flowchart.

\section{Boundary Conditions \& Implicit Dynamics Solver}
% ------------------------------------------------------------------------------

Next, we detail the penalty method for boundary clamping and present the step-by-step Newmark-$\beta$ / Generalized-$\alpha$ implicit time integration algorithm.

Homogeneous Dirichlet clamping at $x=0$ is enforced via the \textbf{Penalty Method} by adding a large stiffness parameter $k_p = 10^{10}$ to diagonal entries of constrained boundary DOFs:
\begin{equation}
    \mat{K}_{\text{eff}}[i, i] \gets k_p, \quad \vect{F}_{\text{eff}}[i] \gets 0 \quad \text{for constrained boundary DOFs } i
\end{equation}
While selecting $k_p = 10^{10}$ increases the condition number of $\mat{K}_{\text{eff}}$, this is an accepted engineering trade-off that avoids complex master-slave DOF elimination while ensuring near-exact zero-displacement clamping.

Algorithm \ref{alg:fom_dynamics} summarizes the step-by-step implicit dynamics solver across $N_t$ time steps.\footnote{The complete JavaScript source code implementing this dynamic time-stepping solver (including matrix assembly, penalty clamped boundary conditions, and direct Gaussian elimination) is verified and available in the repository at \href{https://github.com/WEHBEMUMEN/internship-cnam/blob/main/app/simulations/iga-sim-5.3/src/core/solver.js}{solver.js}.}

\begin{algorithm}[htbp]
    \caption{Full Order Model (FOM) Implicit Dynamics Solver}
    \label{alg:fom_dynamics}
    \begin{algorithmic}[1]
        \Procedure{StepDynamicsFOM}{$x_c, r, \Delta t, N_t$}
        \State Assemble consistent mass $\mat{M}(x_c, r)$ and stiffness matrix $\mat{K}(x_c, r)$
        \State Compute Rayleigh damping: $\mat{C} \gets \alpha_M \mat{M} + \beta_K \mat{K}$
        \State Set Newmark constants: $a_0 = \frac{1}{\beta \Delta t^2}$, $a_1 = \frac{\gamma}{\beta \Delta t}$, $a_2 = \frac{1}{\beta \Delta t}$, $a_3 = \frac{1}{2\beta} - 1$, $a_4 = \frac{\gamma}{\beta} - 1$, $a_5 = \Delta t \left( \frac{\gamma}{2\beta} - 1 \right)$
        \State Formulate effective stiffness: $\mat{K}_{\text{eff}} \gets \mat{K} + a_0 \mat{M} + a_1 \mat{C}$
        \State Apply penalty clamping at left edge ($x=0$): $\mat{K}_{\text{eff}}[i, i] \gets 10^{10}$
        \For{$n = 0, \dots, N_t-1$}
            \State Compute external load vector: $\vect{F}_{\text{ext}}^{n+1} \gets \text{calculateExternalForceVector}(t_{n+1})$
            \State Formulate effective force: $\vect{F}_{\text{eff}}^{n+1} \gets \vect{F}_{\text{ext}}^{n+1} + \mat{M}(a_0 \vect{U}_n + a_2 \dot{\vect{U}}_n + a_3 \ddot{\vect{U}}_n) + \mat{C}(a_1 \vect{U}_n + a_4 \dot{\vect{U}}_n + a_5 \ddot{\vect{U}}_n)$
            \State Apply penalty force condition: $\vect{F}_{\text{eff}}^{n+1}[i] \gets 0$
            \State Solve linear system: $\vect{U}_{n+1} \gets \text{gaussianElimination}(\mat{K}_{\text{eff}}, \vect{F}_{\text{eff}}^{n+1})$
            \State Compute Von Mises stress field: $\sigma_{\text{VM}}^{n+1} \gets \text{computeStress}(\vect{U}_{n+1})$
            \State Update kinematics: $\ddot{\vect{U}}_{n+1} \gets a_0 (\vect{U}_{n+1} - \vect{U}_n) - a_2 \dot{\vect{U}}_n - a_3 \ddot{\vect{U}}_n$
            \State Update velocity: $\dot{\vect{U}}_{n+1} \gets \dot{\vect{U}}_n + (1 - \gamma)\Delta t \ddot{\vect{U}}_n + \gamma \Delta t \ddot{\vect{U}}_{n+1}$
        \EndFor
        \State \Return $\vect{U}_{N_t}$
        \EndProcedure
    \end{algorithmic}
\end{algorithm}

\section{Quantities of Interest (QoI) \& Full Order Responses}
% ------------------------------------------------------------------------------

Here, we extract full-order Von Mises stress distributions and tip displacement time histories to establish physical baseline benchmarks.

High-fidelity Full Order Model (FOM) Von Mises stress concentrations\footnote{The equivalent Von Mises stress $\sigma_{\text{VM}}$ is computed from the displacement field $\vect{u}$ by first calculating the linear strain tensor $\boldsymbol{\varepsilon} = \frac{1}{2}(\nabla\vect{u} + (\nabla\vect{u})^T)$, applying Hooke's law $\boldsymbol{\sigma} = \mat{D}\boldsymbol{\varepsilon}$ under plane stress assumptions, and finally evaluating $\sigma_{\text{VM}} = \sqrt{\sigma_{xx}^2 + \sigma_{yy}^2 - \sigma_{xx}\sigma_{yy} + 3\tau_{xy}^2}$, where $\sigma_{xx}$, $\sigma_{yy}$ are the normal stress components and $\tau_{xy}$ is the shear stress component.} $\sigma_{\text{VM}}$ and displacement magnitude contour fields are depicted in Figure \ref{fig:fom_dynamic_response} and Figure \ref{fig:fom_displacement_response}.

\section{FOM Bottleneck \& Model Parameters}

The following analysis quantifies the online solve times and memory demands of the FOM, highlighting the exact computational bottleneck motivating model reduction.

    \end{description}
