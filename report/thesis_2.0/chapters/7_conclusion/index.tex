% ------------------------------------------------------------------------------
\section{Summary of Achievements}
% ------------------------------------------------------------------------------

Here, we provide a high-level summary of the theoretical, numerical, and engineering milestones accomplished in this thesis.

This thesis has developed a high-speed, client-side application platform for structural dynamics. Key milestones achieved include:

\begin{itemize}[leftmargin=*]
    \item \textbf{Theoretical Foundation}: Formulated exact NURBS geometry evaluations and established smooth parameter-mesh updates via reference domain pullback $\boldsymbol{\Psi}(\boldsymbol{\xi}; \boldsymbol{\mu})$.
    \item \textbf{Full Order Model (FOM)}: Constructed a 2D tensor-product IGA dynamic solver on $E = 3,200$ elements ($N = 6,888$ DOFs).
    \item \textbf{Proper Orthogonal Decomposition}: Extracted a compact $r = 15$ modal basis capturing $>99.999\%$ system energy.
    \item \textbf{ECSW Hyper-Reduction}: Applied Non-Negative Least Squares (NNLS) optimization with coercivity pre-seeding to reduce active integration elements to $E^* = 28$.
    \item \textbf{Application Deployment}: Built a pure client-side JavaScript architecture reaching sub-millisecond solves ($<1.5\,\text{ms}$) at interactive rates ($\ge 60\,\text{FPS}$).
\end{itemize}

% ------------------------------------------------------------------------------
\section{Connection to Research Objectives}
% ------------------------------------------------------------------------------

To validate the framework, the quantitative achievements of this project map directly back to the original research targets established in Chapter \ref{ch:intro}:

\begin{enumerate}[leftmargin=*]
    \item \textbf{Exact Geometry Preservation}: Utilizing the reference pullback mapping $\boldsymbol{\Psi}(\boldsymbol{\xi}; \boldsymbol{\mu})$ ensures zero CAD discretization error across all parameter variations throughout offline and online evaluations.
    \item \textbf{High-Fidelity Dimension Reduction}: Constructing a snapshot Proper Orthogonal Decomposition (POD) reduced basis of rank $r = 15$ captures $99.999\%$ of the system energy with a minimal $0.012\%$ projection error.
    \item \textbf{Efficient Hyper-Reduction}: Implementing reference-mapped Energy-Conserving Sampling and Weighting (ECSW) reduces the active integration mesh to $E^* = 28$ elements, yielding a $64.5\times$ matrix assembly speedup ($2.2\,\text{ms}$ vs. $154.5\,\text{ms}$ for the full order model).
    \item \textbf{Real-Time Application Deployment}: Deploying the reduced solver within a pure client-side WebGL architecture achieves a $1.30\,\text{ms}$ time-step calculation while maintaining interactive graphics refresh rates ($\ge 60\,\text{FPS}$).
\end{enumerate}

Synthesizing these project outcomes confirms that every initial research milestone is fulfilled with high numerical precision and real-time execution speeds.

\section{Future Perspectives \& Research Paths}
% ------------------------------------------------------------------------------

Promising research vectors for extending the framework to nonlinear kinematics, 3D trivariate solids, and multi-patch CAD topologies include:

\begin{itemize}[leftmargin=*]
    \item \textbf{Geometrically Nonlinear Kinematics}: Incorporating Green-Lagrange strains $\mathbf{E}$ and Second Piola-Kirchhoff stress $\mathbf{S}$ with reduced-space Newton-Raphson solvers.
    \item \textbf{3D Continuum Formulations}: Expanding bivariate NURBS surfaces to trivariate NURBS solids for complex 3D volumes.
    \item \textbf{Multi-Patch Topology Assembly}: Integrating Nitsche's method or Mortar element formulations to connect non-isomorphic multi-patch CAD geometries.
    \item \textbf{Adaptive Online Sampling}: On-the-fly basis enrichment to handle extreme parameter excursions beyond initial offline training sets.
    \item \textbf{WebGL Floating-Point Precision Mitigation}: Addressing single-precision (`float32`) WebGL GPU limitations for large-scale structural models via localized origin shifting to prevent loss of precision.
\end{itemize}

\section{Live Application \& Usage Guide}
\label{sec:live_app}
% ------------------------------------------------------------------------------

The complete source code and simulation assets are publicly available on GitHub:
\begin{center}
    \url{https://github.com/WEHBEMUMEN/internship_report}
\end{center}

The application is publicly accessible online at:
\begin{center}
    \url{https://cnam-internship-mumen.netlify.app/}
\end{center}
No installation, server backend, or GPU driver is required — the simulation runs entirely in the browser via WebGL.


\paragraph{Interactive Controls.}
Once loaded, the simulation displays a NURBS clamped-notched beam in real time. The following controls are available:

\begin{enumerate}[noitemsep, leftmargin=1.5em]
    \item \textbf{Notch Position Slider} ($x_c$): Drag left/right to move the notch along the beam axis. The mesh geometry updates instantly via reference pullback — no remeshing occurs.
    \item \textbf{Reduced Basis Selector} ($r$): Choose the number of active POD modes (1 to 15) to observe the trade-off between accuracy and solve time in real time.
    \item \textbf{Solver Mode Toggle}: Switch between \emph{FOM} (full $N=6{,}888$ DOF solve), \emph{Galerkin ROM} (rank-$r$ projection, full assembly), and \emph{ECSW ROM} (rank-$r$, 28 active elements) to compare solvers live.
    \item \textbf{Play / Step / Reset}: Advance the transient Newmark solver one time step at a time, or run continuously. The displacement field and Von Mises stress contours update at $\ge 60\,\text{FPS}$ under the ECSW solver.
    \item \textbf{Export Panel}: Capture the current frame as a high-resolution PNG directly from the WebGL canvas (injected overlay, bottom-right corner).
\end{enumerate}

The stress field is color-mapped from blue (low) to red (high), allowing immediate visual assessment of notch-induced stress concentrations for varying geometric parameters.
